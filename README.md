1. CE ESTE EXPERIENCE FOR ALL?

Experience for All este un program social și educațional non-profit care creează experiențe outdoor și oportunități de educație non-formală pentru copii și adolescenți care locuiesc în case de tip familial aflate în sistemul de protecție a copilului din județul Covasna, România.

Proiectul este realizat în colaborare cu structurile și profesioniștii relevanți din sistemul de protecție a copilului, inclusiv DGASPC Covasna, acolo unde colaborarea este formală și poate fi prezentată public.

2. CE NU ESTE EXPERIENCE FOR ALL?

Este foarte important ca website-ul să NU prezinte proiectul ca:

un club de aventură;

un proiect de scufundări;

un program de divertisment;

o formă de terapie;

un înlocuitor pentru școală;

un serviciu social;

un program psihologic;

o campanie bazată pe milă.

Experience for All este mai mult decât toate acestea.

3. ESENȚA PROIECTULUI

Nucleul proiectului este:

EXPERIENȚĂ → REFLECȚIE → ÎNVĂȚARE → CREȘTERE

Experiența outdoor este cadrul.

Participarea este metoda.

Reflecția transformă experiența într-o oportunitate de învățare.

Învățarea creează posibilități.

Prin urmare:

Experience for All creează experiențe prin care copiii pot descoperi, participa, depăși provocări, reflecta și descoperi noi posibilități.

Acesta trebuie să fie conceptul care leagă întregul website.

4. MISIUNEA

Formulează și prezintă misiunea în jurul următoarei idei:

Fiecare copil merită șansa de a trăi experiențe extraordinare, de a învăța prin ele și de a descoperi de ce este capabil.

Nu folosi un ton de milă.

Nu spune:

„Ajutăm copii săraci.”

Nu spune:

„Acești copii au nevoie de salvarea noastră.”

Nu transforma copiii în obiecte de fundraising.

În schimb:

Copiii merită oportunități.

Copiii merită să descopere.

Copiii merită să participe.

Copiii merită să încerce.

Copiii merită să eșueze în siguranță și să încerce din nou.

Copiii merită să descopere ce pot face.

11. MODELUL EXPERIENCE FOR ALL

Creează o secțiune vizuală foarte puternică:

TRĂIEȘTE → REFLECTEAZĂ → ÎNVAȚĂ → CREȘTE

02 — PARTICIPĂ

Încearcă, cooperează, ia decizii și răspunde provocărilor.

03 — REFLECTEAZĂ

Ce am simțit?

05 — TRANSFERĂ

„Unde pot folosi ceea ce am învățat și data viitoare?”

Aceasta este o parte centrală a filosofiei Experience for All.

46. PRINCIPIUL „NU CERȘIM”

Website-ul nu trebuie să aibă senzația:

Aceasta este diferența dintre fundraising bazat pe milă și fundraising bazat pe participare.

57. CONCEPTUL FINAL

Întregul website trebuie construit în jurul acestei idei:

EXPERIENCE FOR ALL

TRĂIEȘTE. REFLECTEAZĂ. ÎNVAȚĂ. CREȘTE.

Experiența outdoor este cadrul.

Copilul este participantul.

Învățarea este procesul.

Reflecția este legătura.

Comunitatea face experiența posibilă.

Iar scopul final este:

mai multe experiențe → mai multe oportunități → mai multe posibilități.

Construiește un website care nu doar explică acest lucru.

Fă-l să se simtă.

Fotografia trebuie să transmită experiența.

UX-ul trebuie să transmită călătoria.

Conținutul trebuie să transmită sensul.

Impactul trebuie să transmită credibilitatea.
